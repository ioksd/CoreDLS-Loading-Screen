# CoreDLS 5.0

Fabric 1.21.4 client mod project for a dark blue loading screen with falling snow, a time-based greeting, and an animated progress bar.

## Build

Requires Java 21 and Gradle. Run `gradle build`; the mod JAR will be in `build/libs/`.

This project currently shows the screen after the Minecraft client starts; it does not replace Mojang's earliest startup splash.
